### 🎬 Social Media: Backend Platform

A video and social platform backend built API-first.

- 🔐 **JWT auth**, refresh tokens, RBAC and secure password hashing
- 🧩 Core modules for videos, tweets, likes, comments, playlists, subscriptions and channel statistics, with pagination and optimized queries
- 🖼️ **Cloudinary + Multer** for secure image and video uploads
- 📊 **MongoDB aggregation pipelines** for analytics like watch history and engagement insights
- 🧪 Standardized API responses with centralized error handling, workflows validated using **Postman**
